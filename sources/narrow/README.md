# Rob Iosevka 550

Custom source build of Iosevka v34.9.0, commit
2487637bb71f41b2a66134afd9faa6c316e5a438, under the included OFL.
Source checkout: /home/rob/src/iosevka-custom.

Width is 550 units per 1000 em, midway between standard Iosevka Term (500)
and Liberation Mono (approximately 600). This is 8.3% narrower than Liberation
at equal point size. Vertical metrics use Iosevka defaults. Glyph shapes are
regenerated by Iosevka's parametric source, with fresh embedded hint programs,
rather than transforming an existing font's outlines and retaining stale hints.

Includes regular, bold, italic and bold italic. The bold faces use design
weight 600 (semibold), exposed as Bold/weight 700 so terminal bold selection
uses the lighter outlines automatically. Regular remains design weight 400. Hint programs are generated by
ttfautohint 1.8.4 via Iosevka's build. The Ghostty preset uses the launcher's
native-hinting default, so FreeType executes these embedded programs. This is
width customization, not panel-specific hint tuning; QD coverage remains the
terminal renderer's responsibility.

Rebuild: copy private-build-plans.toml to the source checkout; npm ci; then
TTFAUTOHINT_PATH=/home/rob/src/iosevka-custom/local-tools/ttfautohint npm run build -- ttf::RobIosevka550 --jCmd=2
Run under an agent-coord shared CPU/memory lease. The local wrapper supplies
the private ttfautohint library path only to the font build tool.

Install dist/RobIosevka550/TTF/*.ttf and LICENSE.md into
/home/rob/.local/share/fonts/rob-iosevka-550 and run fc-cache on that directory.
Launch: ghostty-qd-font iosevka-550. Normal terminal defaults are unchanged.

Validation: all four faces have 550/1000-em ASCII advances and embedded hint
tables. Vertical hhea metrics match stock Iosevka Term. 2,280 native-hinted
ASCII rasterizations pass at 19, 24, 28, 32, 38 and 42 ppem with pedantic
FreeType checks enabled. Fontconfig resolves bold and italic to the new files.
